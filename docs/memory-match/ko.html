파리의 메모리 매치

카드가 한 장씩 넘어올 때마다 "바로 앞 카드와 같은 냄새인가"에 답하는 게임이에요. 세 마리 파리의 답은 10단계 모델이 실제로 낸 답이에요. "진짜 뇌"는 실제 수컷 초파리 한 마리의 신경 연결 구조(MaleCNS 커넥톰)로 만든 모델이고, "뒤섞인 뇌"는 뉴런과 연결 개수는 그대로 두고 연결 상대만 뒤섞은 것, "뇌 없이 기억만"은 후각 뉴런 신호를 뇌를 거치지 않고 기억 장치에 바로 넣은 거예요. "나도 참가"를 켜면 파리들과 점수를 겨룰 수 있어요.

첫 카드를 기억하세요

벤치마크. 파리들이 학습 때 맡지 않은 냄새 33가지를, 학습 때 쓰지 않은 후각 뉴런으로 보여주는 1,000문항이에요(저장소 10단계의 test B). 파리마다 표시한 "벤치마크" 정답률은 이 1,000문항 전체 기준이고, "이번 판"은 지금 덱 160문항 기준이에요.

결과를 읽는 법. 진짜 뇌 파리는 처음 맡는 냄새를 처음 쓰는 후각 뉴런으로 받아도 같음/다름을 맞혀요. 뒤섞인 뇌 파리와 뇌 없이 기억만 쓰는 파리는 학습 때 본 카드에서조차 우연 수준이라(학습 대신 외우기만 함), 이 게임으로는 "연결 구조 덕분인가"를 판정할 수 없었어요(판정 불가). 메모리 없이 두 카드의 뇌 반응을 코사인 유사도로만 비교하면 진짜 뇌는 같은/다른 냄새를 AUC 0.947로 가르고 뒤섞인 뇌는 0.514예요 — 결과를 본 뒤 한 탐색이라 증거가 아니라 다음 실험의 가설이에요.

무엇이 진짜이고 무엇이 연출인가. 한 번의 비교는 벤치마크의 실제 문항 하나예요: 앞 카드 냄새를 한 무리의 후각 뉴런으로, 빈 프레임 1개 뒤 이번 카드 냄새를 학습 때 쓰지 않은 뉴런으로 받고 답했어요(초기화 씨앗 3개의 평균 확률, 0.5 기준). 이어지는 카드 흐름은 앞 시행의 두 번째 냄새와 다음 시행의 첫 냄새가 같은 시행끼리 이어 붙인 거라, 모델은 비교마다 뉴런을 새로 뽑고 메모리를 새로 시작했어요. 뒤섞인 뇌 파리는 성적이 아니라 번호 순서로 고른 첫 번째 뒤섞기(씨앗 1000)예요. 카드 아래 막대는 수용체 23개 반응(위 흥분, 아래 억제)이고, 파리가 받는 입력은 이 패턴을 뉴런에 무작위로 나눠 넣은 것이라 막대와 똑같지는 않아요.
